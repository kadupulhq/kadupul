These are candidates only. A function is listed when its core reference count is 2 or fewer,
not counting its own definition.
The count is a word-boundary match over tracked PHP files, so it includes comments, strings and
unrelated identifiers, and it counts callers inside `lib/functions.php` itself. A function whose only
caller is another dead function still shows a reference.

`plugins/`, which holds no plugin code, so a zero there is not evidence that no plugin calls the function.

or deprecating anything. Do not remove a function on the count alone.
