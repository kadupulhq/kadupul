# Kadupul 1.3.0-alpha.1 release preparation

This is a preview for isolated evaluation. It is not a production-supported
release and does not provide a supported production migration path. The first
stable target remains 1.3.0. The legacy application/schema compatibility marker
in `include/cacti_version` is separate from the package tag and is unchanged.

## Acceptance before tagging

- Merge the OpenSSF controls in PR #825 with current-head CI and the repository
  review policy, or an explicitly recorded maintainer exception.
- Merge this release preparation with passing artifact acceptance and the same
  review policy or recorded exception.
- Confirm the selected tag commit is on main, contains the versioned changelog,
  and passes main's current-head checks, upgrade/rollback rehearsal, offline
  archive verification and release container acceptance.
- Record the exact source SHA and CI run URLs. Tag that verified SHA as
  `v1.3.0-alpha.1`; do not tag an unreviewed worktree head.

The tag invokes the release workflow. It creates a draft, publishes the signed
container and attaches the dependency-complete offline archive with its checksum
and Sigstore bundle. Only successful verification of both archive and container
provenance makes the draft public. A failed build or verification leaves a draft.

## Compatibility notes

Configured data-input whitelists require valid approvals before collection. Refresh
configured approvals with the input-whitelist CLI when affected methods stop.
Unconfigured installations retain their existing behavior.

Browser plugins must support jQuery 4. The bundled UI and tablesorter workflows
were tested; external plugin compatibility needs validation for this preview.

## Consumer verification

```sh
gh release download v1.3.0-alpha.1 --repo kadupulhq/kadupul \
  --pattern 'kadupul-offline.tar.gz*'
sha256sum --check kadupul-offline.tar.gz.sha256
gh attestation verify kadupul-offline.tar.gz --repo kadupulhq/kadupul \
  --bundle kadupul-offline.tar.gz.sigstore.json \
  --signer-workflow kadupulhq/kadupul/.github/workflows/release.yml
gh attestation verify oci://ghcr.io/kadupulhq/kadupul:1.3.0-alpha.1 \
  --repo kadupulhq/kadupul \
  --signer-workflow kadupulhq/.github/.github/workflows/release.yml
```

A matching checksum alone does not authenticate the release. Keep the successful
verification output and download the source/archive only from the canonical
repository. Evaluate against disposable data; see the documented upgrade and
rollback fixture limits in `docs/testing/release-rehearsal.md`.

After publication, rerun the main Scorecard publishing workflow and verify its
source revision. Complete badge enrollment using actual release and assessment
evidence; publishing this document does not obtain a badge.
