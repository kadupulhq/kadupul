# Code of conduct

## The short version

Be decent to people. Argue about code, not about the person writing it.

## What is expected

Assume the other person is acting in good faith and knows things you do not.
Give criticism about the work, with a reason and a suggested alternative. Accept
criticism the same way. When you are wrong, say so and move on.

## What is not tolerated

Harassment, insults, and personal attacks. Sexualised language or imagery.
Publishing anyone's private information. Sustained disruption of discussions.
Attempting to bait someone into a rule violation so you can report it.

## Scope

This applies in the repositories, the issue tracker, pull requests, and anywhere
someone is representing the project.

## Enforcement

Report a problem to the maintainers privately through
[a security advisory](https://github.com/kadupulhq/kadupul/security/advisories/new),
which is the only private channel this project currently has. Reports stay
between the reporter and the maintainers.

Responses range from a private word, to removal of a comment, to a ban. The
maintainers decide, and will say what they decided and why.
