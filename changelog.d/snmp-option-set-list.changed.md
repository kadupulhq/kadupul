- Serve the SNMP Option Set list selection and its bulk Delete and Duplicate actions through Symfony and Twig under `/automation/snmp-options`; `automation_snmp.php` now only forwards. Both actions need the Automation realm, run on the primary collector, take at most 100 sets, carry a revision per set (a changed set answers 409 and nothing is written) and are audited. Duplicate copies stored SNMP credentials inside the database, copies `bulk_walk_size`, uses the literal `<name>` token in every language and requires each new name to be 1 to 100 characters. Posts of the old bulk forms answer 409.
