- Serve the Graph Rule list selection and its bulk Delete, Duplicate, Enable and Disable actions through Symfony and Twig under `/automation/graph-rules`; `automation_graph_rules.php` forwards its list there and keeps the criteria editor. The actions need the Automation realm, run on the primary collector, take at most 100 rules, carry a revision per rule (a changed rule answers 409 and nothing is written) and are audited. Delete no longer removes the Object Selection Criteria of a tree rule with the same ID. Duplicate uses the literal `<rule_name>` token in every language and requires each new name to be 1 to 255 characters. Posts of the old bulk form answer 409.
